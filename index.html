01 / About

I've always wanted to know how things work.

Growing up, that meant taking things apart — old electronics, broken appliances, anything I could get my hands on — just to see what was inside and how the pieces fit together.

Not everything went back together the way it started. Sometimes I could fix what was wrong or work out the problem; other times I couldn't get it running again — but even then, taking it apart taught me how it was built and showed me exactly where it failed.

That same curiosity eventually pointed itself at software. I started by learning the actual fundamentals of programming — how the pieces fit together and why — and once that clicked, I had what I needed to start building software and websites on my own. I still work the same way I always have: figure out the logic first, then build.

Today I bring that same hands-on, figure-it-out approach to client work: listening closely, building deliberately, and treating every project like something worth getting right.

NS-03 / Donor CRM

Nerd Street CRM

A lightweight donor-management CRM for small nonprofits: donors, donations and follow-ups in one place, so supporters aren't forgotten after their first gift.

For
Small nonprofit teams
My role
Sole developer
Built with
Next.js · React · Prisma · PostgreSQL
Status
Completed
Visit live site: Nerd Street CRM, opens in a new tab ↗

What's inside

  • Donor list with live, debounced search that ranks “starts with” matches first
  • Donor profiles with full donation history; logging a donation updates the donor's totals
  • Creating a donor with a first donation saves both in a single database transaction
  • Sign-in with hashed passwords, and role-based access: admins and team members get different tools
  • An AI decision summary that asks the model for strict JSON, retries once, and falls back to a local summarizer if the reply still can't be parsed
  • A test suite run with Vitest

My part

I was the sole developer — I built Nerd Street CRM myself, from the database schema to the dashboard.

Notes

Learned When an app depends on an AI model's output, require a strict output format and plan for the reply being wrong — that's why the summary retries, then falls back.

Next Keep the AI panel where an admin leaves it between visits, and put raw model replies behind a debug toggle for troubleshooting.
